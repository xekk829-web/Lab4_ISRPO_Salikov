### Git-команды
```bash
git init
git add .
git commit -m "Commit"
git push
```
---
| Команда | Что делает | Примечание |
| :--- | :--- | :--- |
| `git init` | Инициализация git в папке | Обязательная команда для работы с Git |
| `git add .` | Добавляет все изменения в индекс | Точка означает добавляние изменение с текущей папки |
| `git commit -m ""` | Фиксация изменений в коммите | В кавычках пишутся изменения |
| `git push` | Отправка новых коммитов на GitHub-репозиторий | - |
